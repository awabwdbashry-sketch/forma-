# 🏛️ FORMA — العمارة، حين تتحول الفكرة إلى مساحة

✨ **FORMA** هو استوديو عمارة معاصر يقدم تجربة بصرية تفاعلية تعتمد على التمرير لتحويل الفكرة المعمارية إلى شكل ومساحة مكتملة.

## 🚀 المميزات

- 🏗️ تجربة Scrollytelling معمارية تفاعلية
- 🎞️ تسلسل بصري مكوّن من 10 مراحل
- 📊 مؤشر تقدّم أثناء استعراض المشروع
- ✨ انتقالات وحركات سلسة
- ⏳ شاشة تحميل أنيقة
- 🖱️ Custom Cursor
- 📱 تصميم Responsive لمختلف أحجام الشاشات
- 🇸🇩 دعم اللغة العربية واتجاه RTL
- 🖼️ معرض صور للمشروع
- 🔲 تخطيطات معمارية غير متماثلة
- ⚡ Lazy Loading للصور
- 🔤 خطوط Google Fonts مخصصة

## 🛠️ التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Responsive Web Design
- Intersection Observer API
- CSS Animations & Transitions
- Scrollytelling

## ▶️ تشغيل المشروع

لا يحتاج المشروع إلى Backend أو Database.

# 🏛️ FORMA — Architecture, When an Idea Becomes Space

✨ **FORMA** is a contemporary architecture studio experience built around interactive scrolling and visual storytelling, transforming an architectural idea into a complete form and space.

## 🚀 Features

- 🏗️ Interactive architectural Scrollytelling
- 🎞️ 10-stage visual sequence
- 📊 Scroll progress indicator
- ✨ Smooth transitions and animations
- ⏳ Elegant loading screen
- 🖱️ Custom cursor
- 📱 Responsive design
- 🌍 Arabic RTL support
- 🖼️ Project image gallery
- 🔲 Asymmetric architectural layouts
- ⚡ Lazy loading for images
- 🔤 Custom Google Fonts

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Responsive Web Design
- Intersection Observer API
- CSS Animations & Transitions
- Scrollytelling
