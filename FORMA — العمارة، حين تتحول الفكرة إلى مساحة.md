# FORMA — العمارة، حين تتحول الفكرة إلى مساحة

**FORMA** هو موقع تجريبي لاستوديو معماري معاصر، صُمم ليقدم تجربة بصرية وتفاعلية تعتمد على السرد المعماري أثناء التمرير.

الفكرة الأساسية هي تحويل رحلة المشروع من **فكرة أولية إلى شكل معماري مكتمل** إلى تجربة رقمية متتابعة، بحيث يتغير المحتوى والصور مع تقدم المستخدم في الصفحة.

## ✦ عن المشروع

يعتمد FORMA على أسلوب **Scrollytelling**، حيث يصبح التمرير جزءًا أساسيًا من التجربة.

يبدأ الموقع بمقدمة بسيطة تحمل هوية FORMA، ثم ينتقل المستخدم إلى تسلسل بصري مكوّن من عدة مراحل، قبل الوصول إلى المشروع النهائي وتفاصيله.

الموقع يعرض المشروع من عدة زوايا:

- الفكرة
- التكوين
- الشكل النهائي
- المشروع
- الواجهة
- المساحة الداخلية
- الخامات
- الاستوديو
- منهج العمل
- التواصل

## ✦ المميزات

- تجربة Scrollytelling تفاعلية.
- تسلسل بصري من 10 مراحل مع التمرير.
- شريط تقدم يوضح المرحلة الحالية.
- انتقالات وحركات ناعمة بين الأقسام.
- شاشة تحميل عند بداية التجربة.
- مؤشر فأرة مخصص على أجهزة الكمبيوتر.
- تصميم متجاوب مع أحجام الشاشات المختلفة.
- دعم كامل للغة العربية واتجاه RTL.
- معرض صور معماري متعدد الأقسام.
- أقسام تحريرية بتخطيط غير متماثل.
- قسم خاص بالمشروع والواجهة والمساحات والخامات.
- تصميم بصري يعتمد على الأسلوب المعماري الفاخر والبسيط.
- تحميل الصور بطريقة محسّنة باستخدام Lazy Loading.
- استخدام Google Fonts للهوية البصرية.

# FORMA — Architecture, When an Idea Becomes Space

**FORMA** is an experimental website for a contemporary architectural studio, created as a visual and interactive digital experience built around architectural storytelling.

The main concept is to transform the journey of a project — from an **initial idea to a completed architectural form** — into a visual sequence that evolves as the user scrolls through the page.

## ✦ About

FORMA uses a **Scrollytelling** approach where scrolling becomes an essential part of the experience.

The website begins with a minimal introduction to the FORMA identity, then takes the user through a visual sequence before revealing the final project and its architectural details.

The project is presented through several perspectives:

- Concept
- Composition
- Final Form
- Project
- Facade
- Space
- Materials
- Studio
- Process
- Contact

## ✦ Features

- Interactive Scrollytelling experience.
- 10-stage visual sequence.
- Progress indicator for the current stage.
- Smooth transitions and animations.
- Initial loading screen.
- Custom cursor for desktop users.
- Responsive layout.
- Full Arabic RTL support.
- Architectural image gallery.
- Asymmetric editorial layouts.
- Dedicated project, facade, space, and materials sections.
- Minimal and premium architectural visual direction.
- Lazy-loaded gallery images.
- Google Fonts integration.
